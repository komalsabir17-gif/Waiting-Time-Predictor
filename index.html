1. The Smart Waiting-Time Prediction Algorithm

Unlike simplistic queue displays that assign fixed time blocks (e.g. "10 mins per person"), SmartQueue AI uses a discrete stochastic service estimator:

Estimated Wait (T) = Expected Workload Ahead / Sum(Effective Counter Service Capacities)

Specifically, for ticket i with N waiting tickets ahead:
1. Query all operational counters: C = {c_1, c_2, ... c_m} where state != 'PAUSED' and state != 'OFFLINE'.
2. Compute remaining duration for each currently serving counter: Rem(c_k) = Max(1, AvgServiceDuration - ElapsedTime).
3. Simulate earliest completion dispatch queue across active counters to find arrival timestamp.
4. Blend category moving averages with exponential smoothing weights for high-confidence predictions.

Prediction Confidence Metrics

  • Low Confidence: Less than 3 completed visits recorded for that specific category. Falling back to administrator baseline.
  • Medium Confidence: 3 to 9 completed visits recorded. Running blended arithmetic moving average.
  • High Confidence: 10+ completed visits recorded. Statistical outliers trimmed; high predictive stability.

2. Technical Limitations & Engineering Transparency

As a single-file, zero-dependency browser application, this project demonstrates clean software architecture and client-side design patterns:

Browser-Bound Storage
Data is held in HTML5 localStorage. Actions taken in one browser window simulate backend updates for that browser instance.
Simulated Role Authentication
The Customer / Admin switcher demonstrates distinct role-based UX flows without needing a real identity server or OAuth tokens.
Pure Canvas/SVG Graphics
Charts are rendered using standard vector SVG geometry calculations, eliminating heavy third-party plotting libraries.
